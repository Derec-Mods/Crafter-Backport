# Crafter Backport Mod

The Snapshot 23w42a brought us the Crafter, adding automatic crafting, something we thought Mojang would never actually do. Yet it was also added in a very "Minecrafty" way and not something like out of a tech modpack.

This mod reverse engineers the Crafter as accurately as possible, down to the GUI, redstone (with a caveat), and crafting algorithm.

This is still revolutionary, so I decided to continue an early backport of the original https://github.com/QuackImpala7321/AutoCrafterEarly by QuackImpala7321 under the CC0 1.0 Universal license. QuackImpala7321 developed this for only 1.20 to get the Crafter block unlocked earlier before it's 2024 release, so I wanted to add it for even more previous versions, for both Fabric and Forge.

The redstone delay is set to 1 tick instead of the 4 game tick nerf.
